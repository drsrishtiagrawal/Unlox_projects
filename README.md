## 📂 Projects In This Repository

### 1. 💳 SpendDNA (Week 2 - Industry-Graded Minor Project)
> **"Spotify Wrapped for your money."**
* **Description:** A Python transaction analytics engine that parses 6 months of messy Indian UPI/bank statements, extracts canonical vendor names, categorizes spending across 12 sectors, detects spending archetypes, and flags financial anomalies.
* **File:** [`SpendDNA_Srishti.ipynb`](./SpendDNA_Srishti.ipynb)
* **Key Skills:** String processing, datetime parsing, merchant normalization, Z-score anomaly detection, rule-based profiling.

### 2. 🧬 GroupDNA (Week 1 - Social Analytics Project)
